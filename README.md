# Análisis Logístico de Entregas — Olist

## Descripción del proyecto

Proyecto de análisis de datos enfocado en evaluar el desempeño logístico de entregas de la plataforma de comercio electrónico Olist. Se analizaron indicadores de puntualidad, retrasos y tiempos de entrega mediante consultas SQL y un dashboard interactivo.

## Objetivo

Identificar el comportamiento de las entregas y facilitar el seguimiento de indicadores clave de desempeño (KPIs) logístico.

## Herramientas utilizadas

- **Python:** procesamiento y análisis de datos.
- **SQL / BigQuery:** consultas, transformación y agregación de datos.
- **Looker Studio:** visualización de indicadores y creación del dashboard.
- **Git y GitHub:** control de versiones y documentación del proyecto.

## Indicadores principales

| Indicador | Resultado |
|---|---:|
| Pedidos analizados | 96,470 |
| Entregas a tiempo | 93.23 % |
| Entregas retrasadas | 6.77 % |

## Visualizaciones

El dashboard incluye:

- Porcentaje de entregas a tiempo por mes.
- Evolución mensual de pedidos retrasados.
- Tiempo promedio de entrega por mes.
- Tarjetas de indicadores logísticos globales.

## Aprendizajes

- Consulta y agregación de datos mediante SQL.
- Construcción de indicadores clave de desempeño.
- Conexión de BigQuery con Looker Studio.
- Diseño de dashboards para comunicar resultados.
- Validación de métricas globales frente a indicadores mensuales.
